PIN AI Mini App

AI Assistant with Google Workspace Integration

ℹ️ Web Preview: This is a web-accessible version for review purposes. The app is designed to run in Telegram.

Features

  • Complete miniapp interface running in a standard web browser
  • Google OAuth connection flow (Connect/Disconnect)
  • User account management features
  • AI assistant configuration options
  • Subscription and billing interface

About Google OAuth Integration

  • Users can connect their Google account to access Gmail, Calendar, and Drive
  • OAuth scopes requested: Gmail read/send, Calendar read/write, Drive read
  • All credentials are encrypted and stored securely
  • Users can disconnect at any time from the settings

Note: The application is designed to run within Telegram as a Mini App. This web version provides full access for review purposes.
