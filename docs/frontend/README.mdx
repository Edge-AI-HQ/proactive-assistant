# 前端主线 — RN 迁移台账

> 这是一份**轻量入口 + 进度台账**,不是设计细节文档。细节在两份 SSOT 里(见下「详细计划」),本页只回答三个问题:**我们在做什么 / 做到哪了 / 下一步看哪。**

## 使命(一句话)

把 **`proactive-ai-frontend`(Capacitor,当前生产 iOS 前端)逐屏迁移到 `apps/mobile`(Expo React Native)**,做到 iOS 生产功能持平后,**删除 `proactive-ai-frontend`**。最终 iOS 产品由 RN 提供。

- 节奏:**一屏一屏改**,每屏独立可验、单独 PR。
- 路线:**「Share logic, not UI」** —— `@pin-ai/core`(逻辑)/ `@pin-ai/state`(状态)/ `@pin-ai/ui-kit`(组件契约)/ `@pin-ai/design`(token)跨端共享、**直接复用**;UI 在 RN 各写;原生能力(ambient/device)走 port + Expo native module。
- 不动:`apps/web`(桌面端)、后端 `backend`、`ops/` / `loops/` / `internal-reward-dashboard/`。
