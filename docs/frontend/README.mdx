# 前端主线 — RN 迁移台账

> 这是一份**轻量入口 + 进度台账**,不是设计细节文档。细节在两份 SSOT 里(见下「详细计划」),本页只回答三个问题:**我们在做什么 / 做到哪了 / 下一步看哪。**

## 使命(一句话)

把 **`proactive-ai-frontend`(Capacitor,当前生产 iOS 前端)逐屏迁移到 `apps/mobile`(Expo React Native)**,做到 iOS 生产功能持平后,**删除 `proactive-ai-frontend`**。最终 iOS 产品由 RN 提供。

- 节奏:**一屏一屏改**,每屏独立可验、单独 PR。
- 路线:**「Share logic, not UI」** —— `@pin-ai/core`(逻辑)/ `@pin-ai/state`(状态)/ `@pin-ai/ui-kit`(组件契约)/ `@pin-ai/design`(token)跨端共享、**直接复用**;UI 在 RN 各写;原生能力(ambient/device)走 port + Expo native module。
- 不动:`apps/web`(桌面端)、后端 `backend`、`ops/` / `loops/` / `internal-reward-dashboard/`。

## 非屏类收尾(来自 rn-mobile-rebuild 缺口)

不属于"某一屏"、但 sunset 前必须补齐的横切项(详见 SSOT 的 Batch 1/3):

- `App.tsx` wire 4 个注册点:`registerSignOutCleanup` / `registerFeedbackOutbox` / `registerLocalThreadStore` / `registerExternalMicAcquirer`。
- `apps/mobile/src/lib/devices.ts`:`ensureDevice` + expo-secure-store(DeviceCredentials)。
- `ambient/ingest.ts`:内存 buffer → DatabasePort durable outbox。
- ambient 原生 Swift 移植:`capacitor-plugins/ambient-ai`(Capacitor)→ `apps/mobile/modules/ambient-{audio,visit}/ios/`(Expo Module)。

## 完成定义(可以删 proactive-ai-frontend 的前提)

以 [`2026-06-14-rn-mobile-rebuild.mdx`](../plans/2026-06-14-rn-mobile-rebuild.mdx) 的 **Exit criteria** 为准(不在此重复)。一句话:**RN 不再缺 frontend 的功能 + ambient 真数据链路真机验过**,才删 `proactive-ai-frontend` 与 ui-web 的 RN 绑定。

## 验证方式(每屏改完最少跑)

- `cd apps/mobile && npm run type-check`(纯 TS 地基,必过)。
- 动了 `packages/` 共享层:`npm run check:packages`。
- 视觉 / 交互 / 传感器:**真机验收**(模拟器有禁令,见项目记忆);AI 只产代码 + type-check,真机由用户验。
