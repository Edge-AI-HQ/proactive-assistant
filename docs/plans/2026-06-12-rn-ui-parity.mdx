# RN iOS 完全复刻 web UI（2026-06-12 拍板）

> 状态：已拍板开工。执行分支 `feat/rn-ui-chat`（PR #117 扩展为伞 PR）。
> 每刀一个 commit，真机热更/重装逐刀验收。

## 已拍板决策（2026-06-12，用户确认）

1. **复用机制 = NativeWind 4 + 共享 tailwind 设计 token + lucide-react-native（图标同名）+ moti（动效 props 形似 framer-motion）**。组件本体无法跨平台 import（RN 无 DOM/CSS 引擎——这是 Electron 能 100% 复用而 RN 不能的本质），但该组合把逐页翻译降为机械流程：`div→View`、className ~90% 照抄、图标/动效声明照搬。
2. **导航完全照 web**：删 bottom tab；右上 齿轮+汉堡 双圆钮、右侧滑出抽屉（六项大写菜单 + 整页模糊 + 右缘滑入手势）、chat 走底部 ASK PIN AI 上拉（不在菜单）。
3. **Setting 支付页 dev 期全量复刻**（含 Stripe 管理）；上线 App Store 前按审核政策再改。
4. **球面迭代式逼近**：第一版 = 景深+漂浮的玻璃卡片云，随真机反馈逐轮调，最终目标「和网页的感觉一样」。
