# AI Plans

## 结论

`docs/plans/` 只放仍然值得 AI 和团队读取的设计计划。它不是历史归档，也不是临时草稿堆。

主事实仍在 `docs/modules/*.mdx`。AI plan 只解释某个设计为什么这样做、实施时拆过哪些阶段、还有哪些约束需要保留。

## 使用规则

- 本页是**侧边栏 AI Plans 入口**,所有 plan 通过此索引页跳转;具体 plan 不进侧边栏。
- 除本目录说明页 `README.mdx` 外，一个 plan 推荐被至少一个模块文档的 `相关 AI Plans` 引用,但不强制(brainstorm 草稿可以先只挂在此索引)。
- plan 必须等到**对应实现已上线、模块文档已完整吸收设计要点**后,才能删除并从本索引移除。设计阶段或实现进行中的 plan 一律保留 — 它是 implementation 的参照真源,删早了就没法回查决策依据。
- 新 plan 只在跨模块设计、schema 设计、迁移方案、长期约束值得复用时新增。
- 临时 debug 记录、一次性执行日志、过期探索不要放进这里。
- AI 读取顺序是:先读 `docs/index.mdx`,再读相关 `docs/modules/*.mdx`,最后按模块底部的 `相关 AI Plans` 或本索引页继续展开。
