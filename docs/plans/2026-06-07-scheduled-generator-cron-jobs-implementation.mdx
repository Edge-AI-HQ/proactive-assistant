# Scheduled Generator Cron Jobs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Do not commit or push unless the user explicitly asks.

**Goal:** Main Chat 能创建用户确认过的 `generator.scheduled` 定时卡片生成任务,到点后复用现有 scheduler 和 generator pipeline 产出普通卡片。

**Architecture:** 新功能只增加一个薄管理 API 和一个 scheduler kind。创建/管理走 `/api/scheduled-generators/*`;执行仍走 `pai_scheduled_tasks` -> `tick_loop` -> dispatcher -> `_run_generator` -> existing generator pipeline。Main Chat 接入当前 `main` 的 actor-kernel conversation 架构,Settings 接入 `components/account/*`。

**Tech Stack:** Python / FastAPI / psycopg / yoyo SQL migrations / LangChain DeepAgents / React / Vite / Tailwind.

## Non-Negotiables

- Do not create a new cron system.
- Do not create a second scheduled-generator runner.
- Do not rewrite memory retrieval.
- Do not rewrite the generator pipeline.
- Do not move master credentials into chat.
- `generator.scheduled` must execute through existing dispatcher `_run_generator`.
- Main Chat confirmation is reply-based in v1: user replies `确认创建` or `取消`.
- First version does not require action buttons.
