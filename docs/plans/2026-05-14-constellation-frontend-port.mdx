# Constellation 前端整体迁移 Implementation Plan

> **For agentic workers:** 用 Plan agent 或 Inline 模式按 task-by-task 执行；Steps 用 `- [ ]` checkbox 跟踪。

**Goal:** 把 `proactive-ai-frontend` 当前的 `AppShell` UI 整体换成 Lovable repo `proactive-pin-ai` 的 Constellation 设计方案（NOW + 3D sphere + drawer + 多视图 shell），同时**完全保留**当前的卡片执行链路（drawer 点 Approve → POST `/api/feedback` → 在 `MainChatView` 里走 SSE chat-stream 执行）。

**Architecture:** 在 `src/components/constellation/` 下新增一组组件（`ConstellationLayout`、`Sphere3DCards`、`NowFeed`、`CardDrawerDetail`、`AiSphere`、`AmbientView`、`AccountPanel`、`ConnectPanel`），用 `lib/cardAdapter.ts` 把现有 `IntentCard` 映射成 Lovable 的 `Intent` 形态，让视觉组件可以直接消费真实卡片。新增 `useCardActions` hook 把当前 `AppShell` 里的 confirm / dismiss / snooze / modify handler 抽出来复用。最后切 `App.tsx` 把 `<AppShell />` 换成 `<ConstellationLayout />`。

**Tech Stack:** React 18 + Vite + Tailwind + framer-motion (^12.38.0)（已装） + vaul (^1.1.2)（已装） + lucide-react（已装）。**不引入** three.js / @react-three（Lovable 的 Sphere3DCards 用纯 DOM transform）、**不引入** react-router-dom（ConstellationLayout 走自己的 view state machine，跟现状一致）。

**当前分支:** `proactive-ai-v3-UI`（从 `origin/proactive-ai-v3` 切，工作区干净）。**不存在** `src/components/constellation/`。

## 数据映射：IntentCard → Intent

**我们的 IntentCard**（`src/types/intent-card.ts`）：

```typescript
interface IntentCard {
  id: string;
  goalBasket: 'work' | 'health' | 'family' | 'wealth' | 'growth' | 'life';
  title: string;
  whyNow: string;
  summary: string;
  primaryAction: { label: string; type: 'confirm' | 'modify' | 'snooze' | 'dismiss' };
  secondaryActions: IntentCardAction[];
  confidence: number;   // 0..1
  urgency: number;      // 0..1
  importance: number;   // 0..1
  sources: string[];
  agentChain: string[];
  createdAt: string;
}
```

**Lovable Intent**（视觉组件期望）：

```typescript
interface Intent {
  id: number;
  category: string;     // work / health / finance / life / growth / learn
  tag?: string;         // "Urgent" | "Alert" | "Cross Signal" | ...
  complexity?: "simple";
  locked?: boolean;
  title: string;
  line1: string;        // 描述
  line2: string;        // "Sources: Gmail · Notion"
  detail?: {
    scores: { label: string; value: number }[];
    willExecute: string;
    executionPlan: { text: string; tool: string }[];
    dataSources: string[];
    impact: string;
    permissions: string;
    result?: string;
    artifacts?: Artifact[];
  };
  status: "normal" | "new" | "processing" | "done";
  statusTimestamp?: number;
}
```

**映射规则（在 `cardAdapter.ts` 实现）：**

| Lovable Intent 字段 | 来源 |
|---|---|
| `id` | hash of `card.id` (string → stable number) |
| `category` | `goalBasket` 直接当 category；`wealth` → `finance`、`family` → `life` 适配（categoryMeta 自己解决） |
| `tag` | `card.urgency >= 0.85` → `"Urgent"`；否则 undefined |
| `title` | `card.title` |
| `line1` | `card.whyNow \|\| card.summary` |
| `line2` | `card.sources` join `" · "`（前缀 `"Sources: "`） |
| `complexity` | undefined（暂不用） |
| `locked` | undefined（暂不用） |
| `detail.scores` | `[{ Confidence: round(confidence*100) }, { Importance }, { Urgency }]` |
| `detail.willExecute` | `card.primaryAction.label` |
| `detail.executionPlan` | **hardcode**：`[{ text: primaryAction.label, tool: deriveTool(sources) }]`（v1 给一个 step；后端真有 plan 了再补） |
| `detail.dataSources` | `card.sources` |
| `detail.impact` | `""`（v1 hardcode 空字符串，视觉上隐藏 section） |
| `detail.permissions` | `""`（同上） |
| `status` | `processingIds.has(card.id) ? "processing" : doneIds.has(card.id) ? "done" : "normal"`（由 ConstellationLayout 注入） |

`Intent.id` 改成 number 的原因：Lovable 视觉组件用 number 比较 + `key`。我们用 stable hash（djb2）把 string id 转成 number。**保留 `originalId: string`** 字段在 adapter 输出里，供事件回调反查我们的真实 IntentCard。

```typescript
// proactive-ai-frontend/src/lib/cardAdapter.ts
import type { IntentCard, GoalBasket } from "@/types/intent-card";
import type { Intent, CardCategory, CardStatus } from "@/types/constellation";

/** djb2 — 把 string id 稳定 hash 到 number。同一 string 永远得同 number。 */
function djb2(str: string): number {
  let h = 5381;
  for (let i = 0; i < str.length; i++) h = ((h << 5) + h) ^ str.charCodeAt(i);
  return Math.abs(h | 0);
}

/** GoalBasket → 视觉 category。wealth/family 不在 Lovable category 里，做映射。 */
function basketToCategory(basket: GoalBasket): CardCategory {
  switch (basket) {
    case "wealth": return "finance";
    case "family": return "life";
    case "work":
    case "health":
    case "growth":
    case "life":
      return basket;
    default:
      return "life";
  }
}

export interface AdapterOptions {
  status: CardStatus;
}

export function intentCardToIntent(card: IntentCard, opts: AdapterOptions): Intent {
  const line1 = card.whyNow && card.whyNow.trim().length > 0 ? card.whyNow : card.summary;
  const line2 = card.sources.length > 0 ? `Sources: ${card.sources.join(" · ")}` : "";
  const tag = card.urgency >= 0.85 ? "Urgent" : undefined;

  return {
    id: djb2(card.id),
    originalId: card.id,
    category: basketToCategory(card.goalBasket),
    tag,
    title: card.title,
    line1,
    line2,
    status: opts.status,
    detail: {
      scores: [
        { label: "Confidence", value: Math.round(card.confidence * 100) },
        { label: "Importance", value: Math.round(card.importance * 100) },
        { label: "Urgency", value: Math.round(card.urgency * 100) },
      ],
      willExecute: card.primaryAction.label,
      executionPlan: [],   // v1: 不 hardcode 假步骤，留空，视觉组件应能优雅隐藏 section
      dataSources: card.sources,
      impact: "",
      permissions: "",
    },
  };
}

export interface BulkAdapterContext {
  processingIds: Set<string>;
  doneIds: Set<string>;
}

export function intentCardsToIntents(cards: IntentCard[], ctx: BulkAdapterContext): Intent[] {
  return cards.map((c) => {
    const status: CardStatus = ctx.processingIds.has(c.id)
      ? "processing"
      : ctx.doneIds.has(c.id)
        ? "done"
        : "normal";
    return intentCardToIntent(c, { status });
  });
}
```

参照 `AppShell.tsx:120-129`（state）和 `AppShell.tsx:269-395`（handlers），把以下提到 hook 里。**保留原 AppShell 不动**（这样旧代码继续能跑）。

```typescript
// proactive-ai-frontend/src/hooks/useCardActions.ts
import { useCallback, useEffect, useState } from "react";
import { proxyPost } from "@/lib/api";
import type { IntentCard } from "@/types/intent-card";

const CHATTED_KEY = "pai.constellation.chattedCardIds";

function loadChatted(): Set<string> {
  try {
    const raw = sessionStorage.getItem(CHATTED_KEY);
    if (!raw) return new Set();
    return new Set(JSON.parse(raw));
  } catch { return new Set(); }
}

function saveChatted(ids: Set<string>) {
  try { sessionStorage.setItem(CHATTED_KEY, JSON.stringify([...ids])); } catch {}
}

export interface UseCardActionsOptions {
  /** confirm 后回调：(card, bootstrapMessage) — 调用方负责把 chat 屏切出来。 */
  onOpenChat: (card: IntentCard, bootstrapMessage: string) => void;
}

export function useCardActions({ onOpenChat }: UseCardActionsOptions) {
  const [processingIds, setProcessingIds] = useState<Set<string>>(new Set());
  const [doneIds, setDoneIds] = useState<Set<string>>(new Set());
  const [confirmedIds, setConfirmedIds] = useState<Set<string>>(new Set());
  const [dismissedIds, setDismissedIds] = useState<Set<string>>(new Set());
  const [chattedCardIds, setChattedCardIds] = useState<Set<string>>(() => loadChatted());

  // 初始化 dismissedIds：从 /api/feedback/dismissed 拉
  useEffect(() => {
    let abort = false;
    (async () => {
      try {
        const res = await proxyPost<{ ids: string[] }>("/feedback/dismissed", {});
        if (!abort && res?.ids) setDismissedIds(new Set(res.ids));
      } catch { /* ignore */ }
    })();
    return () => { abort = true; };
  }, []);

  const persistChatted = useCallback((id: string) => {
    setChattedCardIds((prev) => {
      if (prev.has(id)) return prev;
      const next = new Set(prev); next.add(id); saveChatted(next); return next;
    });
  }, []);

  const confirm = useCallback(async (card: IntentCard) => {
    setProcessingIds((s) => new Set(s).add(card.id));
    setConfirmedIds((s) => new Set(s).add(card.id));
    persistChatted(card.id);
    try {
      await proxyPost("/feedback", {
        kind: "card_action",
        action: "confirm",
        cardId: card.id,
        runId: null,
      });
    } catch { /* swallow; UI 已经 optimistic */ }
    onOpenChat(card, card.primaryAction.label);
  }, [onOpenChat, persistChatted]);

  const dismiss = useCallback(async (card: IntentCard) => {
    setDismissedIds((s) => new Set(s).add(card.id));
    try {
      await proxyPost("/feedback", {
        kind: "card_action",
        action: "dismiss",
        cardId: card.id,
        runId: null,
      });
    } catch {}
  }, []);

  const snooze = useCallback(async (card: IntentCard) => {
    try {
      await proxyPost("/feedback", {
        kind: "card_action",
        action: "snooze",
        cardId: card.id,
        runId: null,
      });
    } catch {}
  }, []);

  const modify = useCallback(async (card: IntentCard) => {
    persistChatted(card.id);
    onOpenChat(card, "");   // 进 chat 但不发 bootstrap，等用户输入
  }, [onOpenChat, persistChatted]);

  const done = useCallback(async (card: IntentCard) => {
    setDoneIds((s) => new Set(s).add(card.id));
    setProcessingIds((s) => { const n = new Set(s); n.delete(card.id); return n; });
    try {
      await proxyPost("/feedback", {
        kind: "card_action",
        action: "done",
        cardId: card.id,
        runId: null,
      });
    } catch {}
  }, []);

  const openChat = useCallback((card: IntentCard) => {
    persistChatted(card.id);
    onOpenChat(card, "");
  }, [onOpenChat, persistChatted]);

  const textFeedback = useCallback(async (card: IntentCard, text: string) => {
    if (!text.trim()) return;
    try {
      await proxyPost("/feedback", {
        kind: "text_feedback",
        cardId: card.id,
        runId: null,
        text: text.trim(),
      });
    } catch {}
  }, []);

  return {
    processingIds, doneIds, confirmedIds, dismissedIds, chattedCardIds,
    confirm, dismiss, snooze, modify, done, openChat, textFeedback,
  };
}
```
