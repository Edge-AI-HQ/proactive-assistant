# 老 Memory 架构 Sunset → Adapt 实施方案

> **状态**:实施中(2026-06-24)。承接 [Lifelong Memory 实施方案 §六](./2026-06-23-lifelong-memory-implementation) 的完整 sunset roadmap。前序 PR 已落地新三层 + P6 消费侧(chat/generation)+ P7-A(私有工具删除)。本方案 = 剩余 sunset(老表/老 API/前端/reward-dashboard 全切 + 物理删除)。

## 〇、已定决策(用户 2026-06-24 拍板)

| 张力 | 决策 |
|---|---|
| 画像 markdown vs 结构化 UI | **A:前端直接渲染 markdown**,接受丢结构化卡片 |
| Goals 退役 | 接受退化成 GOALS markdown 列表 |
| MemoriesPanel(debug) | **废弃**(CRUD 模型新架构没有;画像 agent 维护用户不直接编辑;查看由 Mirror+Ambient 覆盖) |
| Dream Journal | 改名 **Evolution** + 审计结构改:profile/goal diff → events curated + portrait edits diff;dream markdown → evolve reasoning |
| `pai_profile` 拆 | display_name/locale/timezone **留 `pai_user_settings`**;persona(summary/facts/preferences/constraints)→ 画像 USER |
| onboarding goals | **选项 a:seed 一段默认 GOALS markdown**(保留新用户"目标骨架"体验) |

**数据形状分工**:
- **Mirror**(Identity + Goals)= 渲染 L2 画像 markdown(USER/MEMORY → Identity,GOALS → Goals tab),纯只读。
- **Ambient timeline** = L1 events 活动流(device 切 events 后)。
- **Evolution**(原 Dream)= evolve 审计(`pai_evolution_runs` + events curated + portrait edits)。

## 一、阶段与落点

### S1 · 后端解耦 + 数据源切换(纯 backend,先做,不碰前端)
**目标**:斩断老表所有自动写入,消费侧只读新架构;老表进入"只剩存量、零新数据"。

1. **feedback 解耦**:`domains/feedback/repository.py:194` `PreferenceRepository.add` → `event_append(event_type=preference, source=pinai_feedback, structured={scope,polarity,weight})`。
2. **device 摄入切**:`connector/device/devices_ui.py:583` + `device_ingest/` signal_only policy:`PersonalSignalsRepository.ingest_one` → 写 `pai_raw`(device scope),projector 自动进 events。device timeline UNION 改读 pai_raw/events。
3. **phase1_seed 切**:`orchestration/phase1_seed.py` 5 个 `_collect_*` 从 `pai_events` 投影 pattern_matcher 形状(calendar.events/gmail.unresponded_to_vip/memory.recurring_obligations),保契约。
4. **generation_context 去 legacy**:`agent-engine/agents/generation_context.py` 移除 P6 并存的 memory/signals/preferences 调用(portrait+events 已接管)。
5. **onboarding 切**:`domains/identity/onboarding.py` + `orchestration/default_goals.py`:display_name/locale/tz → `pai_user_settings`;seed 默认 **GOALS markdown** 进 `pai_user_strings`;初始 persona 进 USER(或留空让 evolve 填)。
6. **ProfileRepository 拆**:settings 方法(`get_settings`/`upsert_settings`)抽到 `domains/user_model/settings.py`;profile/goals 方法标记待删;dispatcher/notification/control 的 `get_settings` 调用改指向。

### S2 · UI 面新端点(current_user 鉴权,给前端)
1. `GET /api/user-strings`(current_user)→ 画像 6 段 markdown。
2. `GET /api/events`(current_user)→ events 时间线(默认 active,可选 type/since)。
3. `/api/dreaming` → `/api/evolution` 改名:读 `pai_evolution_runs` + 每 run 的 events curated + portrait edits diff(替代 profileDelta/goalDelta)。

### S3 · 前端三端切换
1. **packages/core**:新域函数 `fetchPortrait`/`fetchEvents`/`fetchEvolutionRuns` + 类型;删 `fetchMemories`/`fetchProfileSnapshot`/`fetchSignals` + Memory/ProfileRecord/PersonalSignal 类型。
2. **packages/state**:新 hooks `usePortrait`/`useEvents` 替 `useProfileSnapshot`/`useMemories`/`useProfileMemories`。
3. **Mirror**(MirrorDesktop/Mobile + ui-web/mirror):Identity 渲染 USER/MEMORY markdown,Goals tab 渲染 GOALS markdown。
4. **Ambient**(AmbientScreen/View):`fetchSignals` → `fetchEvents`,timeline 字段映射。
5. **AutoDreamingSettings → EvolutionSettings**:改名 + 详情结构改。
6. **ProfileScreen**(RN):同 Mirror。
7. **MemoriesPanel**:删除(废弃)。

### S4 · reward-dashboard
`personal_data_snapshot.py` 的 4 老表读取 → events/画像/pai_raw 派生。

### S5 · 物理删除(最后,确认无消费者)
1. 删 API:UI 面(memory_ui/signals_ui/profile_ui profile-goals/preferences_*)+ agent 面(memory_agent/signals_agent/profile_agent/preferences_agent)。
2. 删 repo:Memory/PersonalSignals/Preference + ProfileRepository profile/goals 方法。
3. 删 SDK:`client.{memory,signals,profile,preferences,raw}`。
4. 删 contract:`MemoryItem`/`PersonalSignal*`/`Profile*`/`Goal*`/`Preference*`。
5. **DROP 表**:pai_memory/personal_signals/profile/goals/preference_records + 17 typed raw + RLS policy;`pai_embedding_queue` CHECK 去退役表。
6. `app.py` 摘退役 router。
